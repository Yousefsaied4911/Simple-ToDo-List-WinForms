
# 📝 Simple To-Do List App (C\# WinForms)

A simple and clean To-Do List application built using **C\#** and **Windows Forms (WinForms)**.

This was my **first full project**, created to practice essential concepts like Windows Forms, **event handling**, fundamental **data structures**, and **UI logic**.

-----

## 🚀 Key Features

This application includes robust task management features and a smooth user experience:

  * **Task Management:**
      * **Add** new tasks easily.
      * **Remove** a selected task.
      * **Remove** the last added task.
      * **Edit** task names directly (inline rename).
      * **Delete** task via the right-click context menu.
      * **Clear All** tasks.
  * **Progress Tracking:**
      * **Check/Uncheck** tasks to mark them as complete/incomplete.
      * Task **icons change** automatically based on their checked state.
      * A **Progress Bar** updates automatically to reflect the completion percentage.
  * **Advanced Functionality:**
      * **Undo / Redo System:** Implemented using a **Stack** data structure combined with full **TreeView cloning** to manage state history.
      * **Input Validation** to prevent empty task entries.
      * **Smooth UI** experience.
