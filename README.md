# ToDo List App (C# WinForms)

A simple To-Do List app with:
- Add, Remove, Edit tasks
- Undo / Redo
- Clear All
- Progress Bar linked with checked tasks
- Context Menu and Icons

Built as my **first complete C# project** to practice Windows Forms and basic UI/UX.

## How to Run
1. Open in Visual Studio
2. Build & Run (F5)
